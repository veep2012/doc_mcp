while the un-awaited coroutine indicates incomplete async test coverage or a
resource leak in the exercised path.

adding the dependency audit as a CI quality gate. Fixing the warning requires
isolating the dependency-version interaction and the crawler test lifecycle.

### Proposed Fix

call sites, then either align the compatible MCP/Pydantic dependency versions

the unit suite to run without runtime warnings.
